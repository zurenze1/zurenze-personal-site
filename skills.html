01 / macOS 应用

工具箱

解决的问题：看英文网页、软件和截图时要来回切换翻译；截图、下载视频又分散在多个工具里。

主要功能

  • 屏幕中文：在本机识别屏幕上的英文并翻译，支持全屏翻译（⌥T）
  • 网页自动翻译：直接替换网页文字，保留原有链接和按钮，可切回原文
  • 截图中转站：截图后先存起来，再做翻译
  • 视频下载：下载抖音等平台视频，并提示是否已去水印

技术栈

  • Swift
  • macOS 原生
  • WebKit
  • Apple Vision
  • yt-dlp
  • ffmpeg

我的角色

提出需求、设计产品，用 AI 编程助手开发并迭代到 3.2.0 版本。

02 / Web 应用

内容创作工作台

解决的问题：做人物故事、人物解读和读书分享时，素材、出处、选题和脚本版本散落各处，难以追溯。

主要功能

  • 素材采集，并能追溯到原始证据
  • 从热点到选题：给不同的个人 IP 分别记录原创角度和资料缺口
  • 制作看板，项目内分素材证据、脚本镜头、审稿交付、发布登记四步
  • 审稿锁定具体版本，改稿后需重新确认

技术栈

  • React
  • Vite
  • TypeScript
  • Fastify
  • Anthropic SDK
  • Tesseract.js

我的角色

写产品需求文档（PRD），定下开发约束，用 AI 编程助手实现到 0.7.0 版本。

03 / 开源桌面应用

人生档案 Life Archive

解决的问题：一闪而过的想法、读书领悟和做事经验容易忘，写日记又常因为打字麻烦而中断。

主要功能

  • 每天说几句：保存原文、原始录音和时间
  • 整理结果可以回溯到原句
  • 数据存在本地，不用注册；免费开源（MIT）
  • 提供 Mac 版和网页版

技术栈

  • Electron
  • Node
  • electron-builder
  • 早期网页版：Next.js · Cloudflare

我的角色

发起人和开发者，负责产品、开发和开源发布。

04 / 全栈网站

祖仁泽热点 · AI 热点站

解决的问题：AI 消息太多，很难判断哪条值得读、值得试，或值得拿来做内容。

  • 数据库迁移

05 / 本地 AI 工具

本地克隆音试用台

解决的问题：想给口播视频配上自己的声音，但不清楚哪个开源语音克隆模型效果最好，也不想把录音上传到云端。

主要功能

  • 在本机比较 IndexTTS、OmniVoice、VoxCPM2、LongCat、F5 等模型
  • 添加本人原声、输入文案即可试听
  • 支持本地语音识别
  • 只在本机运行，参考录音不出电脑

技术栈

  • Python
  • MLX
  • 本地 HTTP 服务
  • 离线推理

我的角色

提出需求、选型并验证模型，用 AI 编程助手搭建试用台。
