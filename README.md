# 祖仁泽个人网站

中文多页面个人网站。个人信息与自然彩色照片来自本人提供的飞书文档。

当前版式按照 https://www.pinterest.com/pin/25966135349298914/ ：通栏细线网格、超大中文标题、四张并排照片、蓝色侧栏与六格个人资料、生活片段、三栏联系区和分格页脚。保留米白、荧光黄绿与电光蓝，照片不做灰度或染色处理。

五页：首页、关于我、个人经历、阅读与生活、保持联系。阅读与生活保留五个阅读入口和两首钢琴演奏链接。

本地预览：npm run dev，默认 http://localhost:5173 。可设置 PORT 使用其他端口。

Sites 源码：hosted-site/dist/。GitHub Pages：github-site/。
