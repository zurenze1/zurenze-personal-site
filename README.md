# 祖仁泽个人网站

中文个人网站。保持自然彩色照片与现有深绿、暖纸配色，用清晰的主题组织真实经历。

- 首页：29 张个人照片组成可自动旋转、拖动、暂停和放大的照片球；首屏直接播放自我介绍和军旅回忆，下方并列展示两个视频封面与六个主题入口。
- 内容归位：军旅 5 张照片与完整军旅视频；工作 3 张；校园 2 张；旅行 12 张；阅读与日常 6 张；关于我 1 张正式肖像与自我介绍视频。29 张完整照片在各自主题页只出现一次，首页使用轻量缩略图作为入口。
- 页面：首页、关于我、军旅与工作、旅行、阅读与日常、家乡、联系。移除独立相册导航，旧 photos.html 按锚点转到对应主题，避免旧链接失效。
- 所有个人照片的对应主题与原图路径记录在 assets/stories.json。原始素材不删除；民族服装属于外出旅行，不作为贵州或贵阳的介绍配图。
- 动态：短入场、照片球、滚动渐入、导航提示、唱片旋转。支持手动关闭、系统减少动态与后台暂停。关闭动态时照片球改为可横向浏览的静态照片列。
- 两个视频保持原声、完整时长（2:49 / 2:25），首页弹层直接观看，对应主题页也能观看；播放时暂停其他音视频，关闭弹层释放视频资源。
- 五本书提供免费简介和书摘；《六祖坛经》另有 Project Gutenberg 免费全文与下载入口。其余现代书籍的正规平台可能需要登录或付费。
- 站内卡农和背景音乐使用 Lee Galloway 授权音频（Wikimedia Commons，CC BY-SA 3.0），无第三方广告播放器。Flower Dance 是创作者的站外链接，平台可能有广告。
- 邮箱 2966766140@qq.com，微信 jzzt779；保留抖音主页与人生档案项目入口，不虚构作品或数据。

根目录用于编辑与预览，github-site 为 GitHub Pages 发布仓库，hosted-site/dist 为 Sites 产物。公开输出不包含原始素材归档、测试截图或本地路径。检查命令：npm run check。
