# 祖仁泽个人网站

中文个人网站，以清晰的文字层级、深蓝色与自然彩色照片，呈现真实经历、阅读和日常生活。

- 首页：小幅彩色肖像与文字开场、抖音作品入口、IP课程自我介绍视频、四段经历切换、五本书的主题书架，以及生活照片。
- 内页：关于我、个人经历、贵州贵阳、阅读与生活、保持联系。
- 正式肖像放在“关于我”；民族服装照片属于外出旅行，不作为贵州或贵阳的介绍配图。
- 五本书可进入独立书摘，保留简介、短句出处、阅读问题与延伸阅读入口。
- 卡农使用 Lee Galloway 的完整钢琴音频（Wikimedia Commons，CC BY-SA 3.0）；Flower Dance 使用 DJ OKAWARI 发布的 SoundCloud 音频。音乐区与背景音乐互相暂停，背景音量默认 12%。浏览器拦截自动播放时，可点击开关开启。
- 六页都带移动目录、键盘焦点、背景音乐开关与音量控制。图片保持自然色彩。

根目录是编辑与本地预览用文件；`hosted-site/dist/` 用于 Sites 发布，`github-site/` 用于 GitHub Pages。公开目录只包含网站文件与素材，不包含调试记录或预览截图。

这次排版研究参考了 [Paco Coursey](https://paco.me/) 和 [Frank Chimero](https://frankchimero.com/) 的个人站，并根据中文阅读和本人的内容重新设计。
