# 祖仁泽个人网站

中文多页面网站。个人资料和照片来自本人提供、2026 年 10 月 5 日更新的飞书文档。照片保留原色，通过构图、留白和蓝色/黄绿色边框配合网站视觉；新增工作活动、跑步、棒球、海边生活照片。

网站结构借鉴 https://xiaochens.com/ 的全屏导航与多页面形式。当前视觉参考 https://www.pinterest.com/pin/25966135349298914/ ：米白、荧光黄绿、电光蓝，粗黑大字、细线网格、方形照片卡片和黑色内容区。

本地预览：npm run dev，打开 http://localhost:5173 。

五页：首页、关于我、个人经历、阅读与生活、保持联系。共享样式 style.css，全屏导航 script.js，照片 assets/。

Sites 发布源码：hosted-site/dist/。GitHub Pages 仓库：github-site/。
