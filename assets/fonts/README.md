# Website fonts

Local WOFF2 subsets of Google Fonts variable fonts, retrieved 2026-10-12:

- Noto Sans SC (100–900): https://github.com/google/fonts/tree/main/ofl/notosanssc
- Manrope (200–800): https://github.com/google/fonts/tree/main/ofl/manrope

Both are licensed under SIL Open Font License 1.1. Original license files are included here. Subsets retain variable weights; Chinese glyph coverage includes this site's current content, with system font fallback for future characters. Font data has been subset and WOFF2 compressed with fontTools; no visual glyph designs were changed.
